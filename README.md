# ⚡ THE PROTOCOL WIFITE
**Author:** Laltesh Chaudhary

A dark-themed GUI Wi-Fi scanner and direct pairing utility for Kali Linux and Debian-based systems.

## Quick Install & Run

    git clone [https://github.com/CrackerHacker451/protocol-bluebuck.git](https://github.com/CrackerHacker451/protocol-bluebuck.git)
    cd protocol-bluebuck
    chmod +x install.sh && ./install.sh
    xhost +SI:localuser:root >/dev/null 2>&1 && sudo -E protocol-bluebuck
